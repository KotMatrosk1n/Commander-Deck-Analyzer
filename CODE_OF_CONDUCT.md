# Code of conduct

Commander Deck Analyzer welcomes respectful, focused collaboration.

Participants are expected to:

- discuss ideas and code without personal attacks
- give specific, actionable feedback
- respect different experience levels and backgrounds
- keep issue and pull request discussions relevant
- protect user data and report security concerns responsibly

Harassment, discrimination, threats, deliberate disruption, or publication of
another person's personal information is not acceptable.

Repository maintainers may edit, remove, or reject contributions and comments
that do not follow these expectations. Serious concerns can be reported through
the security route described in [SECURITY.md](SECURITY.md).
