## Highlights

Commander Deck Analyzer 0.0.1 is the first public Windows release. It analyzes
Commander deck structure, opening hands, mana development, supported win
routes, interaction pressure, and modeled threat timing on your computer. Every
report shows the evidence behind its bracket estimate and identifies limits in
the current rules model.

## Analysis and Scoring

* Opening hand sampling follows a fixed aggressive multiplayer London mulligan
  policy.
* Reports cover mana, color access, synergy, resilience, and supported routes.
* Four interaction profiles range from No Interaction through cEDH
  Interaction.
* Bracket recommendations include supporting reasons, confidence limits, and
  visible coverage gaps.
* Trial counts include 1,000, 5,000, and 10,000. Results are not reused after
  rules or analysis behavior changes.

## Rules, Simulation, and Coverage

* The rules engine accepts a card function only when it can execute the complete
  Oracle clause.
* Reports show unsupported card behavior instead of hiding it.
* Route reports include timing, blocker provenance, recovery modeling, and
  interaction handling.
* Alternate printed card names resolve through card identity data.
* Saved reports and cached results are rejected when simulation, rules
  coverage, or scoring behavior changes.

## Data and Imports

* Deck lists can be pasted, opened from supported files, or imported from
  supported public deck URLs.
* Card lookups and snapshot updates run only when requested from inside the
  app.
* Analysis data and caches stay on the computer. Reports are saved only where
  the user chooses.

## App and Workflow

* The Windows desktop interface keeps deck setup, analysis options, reports,
  and Markdown export in one place.
* Reports bring together coverage details, route provenance, opening hand
  results, threat timing, synergy, and bracket evidence.
* Release drafts include version checks and checksums.

## Documentation

* Guides cover analysis, data sources, architecture, development, security, and
  releases.
* Public documentation explains the limits of bracket estimates, interaction
  profiles, data use, and network access.

## Known Limitations

* Bracket and timing estimates are not yet calibrated against a large
  independent set of real games.
* The analyzer models supported routes and card functions. It is not a complete
  Magic game engine.
* The Windows installer is unsigned. Windows may show a SmartScreen or publisher
  warning.
